# [10조 컴미컴]: 월계ON-AI

> 사진 한 장으로 시작하는 우리 동네 소상공인 홍보와 골목상권 탐방 서비스

## 프로젝트 소개

**월계ON-AI**는 서울 노원구 월계1동의 소상공인과 주민을 연결하는 지역 상권 활성화 서비스입니다.

소상공인은 홍보 문구, 카드뉴스, SNS 운영에 필요한 시간과 전문 인력이 부족하고, 주민은 가까운 가게의 신메뉴와 할인 정보를 제때 발견하기 어렵습니다. 월계ON-AI는 이 정보 격차를 AI 홍보 자동화와 라이브 동네 지도로 줄이고, 방문 퀘스트를 통해 실제 골목상권 방문으로 이어지게 합니다.

## 해결하려는 문제

- 소상공인의 온라인 노출과 디지털 홍보 역량 부족
- 신메뉴, 할인, 재고 소진 등 동네 가게의 실시간 정보 전달 부족
- 익숙한 프랜차이즈와 대형 매장에 집중되는 소비
- 고령 주민과 이동약자가 이용하기 어려운 디지털 서비스

## 핵심 기능

### 1. AI 홍보물 생성

가게 사장님이 제품 사진 한 장과 간단한 키워드 또는 음성을 입력하면 AI가 홍보 콘텐츠를 생성합니다.

- 주민 친화형, 트렌디형, 가성비형 문구 생성
- 카드뉴스 및 숏폼 홍보 소재 생성
- 월계1동 대학생, 주말 가족 등 지역 특성에 맞는 키워드 추천
- 생성된 홍보 문구의 TTS 음성 변환

### 2. 라이브 동네 지도

주민은 별도 앱 설치나 로그인 없이 웹에서 동네 가게와 실시간 소식을 확인할 수 있습니다.

- 지도 위 매장별 홍보 콘텐츠 및 이벤트 표시
- 오늘의 신상품·할인 피드
- 매장 정보, 메뉴, 운영시간 확인
- 가게의 턱 유무, 엘리베이터 등 배리어프리 정보 제공

### 3. GPS 기반 상권 탐방 퀘스트

지도에 표시된 매장을 직접 방문하고 퀘스트를 완료하면 마일리지와 리워드를 받을 수 있습니다.

- GPS 기반 방문 인증
- 여러 매장을 순회하는 테마별 탐방 코스
- 방문 스탬프 및 마일리지 적립
- 쿠폰 또는 지역 상권 혜택으로 연결되는 리워드

### 4. 접근성을 고려한 서비스 설계

월계1동의 다양한 연령대 주민이 함께 사용할 수 있도록 정보 접근성을 우선합니다.

- 큰 글씨와 큰 버튼 중심의 간편한 UI
- 음성으로 들을 수 있는 홍보 콘텐츠
- 매장별 접근성 정보 태그
- 주민 누구나 이해하기 쉬운 지도와 정보 구조

## 지역 데이터 기반 문제 정의

월계1동은 20대와 60대 이상 주민이 주요 유동인구 축을 이루며, 매출은 주말과 17~21시에 집중되는 특성이 있습니다. 이러한 지역 특성 때문에 학생층의 소비를 골목 안쪽 매장으로 확산하고, 고령 주민도 쉽게 접근할 수 있는 정보 제공 방식이 필요합니다.

회의에서 정리한 주요 근거는 다음과 같습니다.

- 월계1동 총인구: 20,133명
- 60세 이상 인구: 6,090명
- 20~29세 인구: 3,654명
- 유동인구가 가장 높은 시간대: 17~21시
- 주중보다 높은 매출이 나타나는 요일: 토요일

## 서비스 이용 흐름

```text
사장님: 사진·키워드 입력
				↓
			AI 홍보 문구·이미지·음성 생성
				↓
			라이브 동네 지도와 오늘의 피드에 게시
				↓
주민: 가게 발견 → 퀘스트 참여 → GPS 방문 인증
				↓
			마일리지·쿠폰 획득 및 골목상권 재방문
```

## 기대 효과

- 소상공인의 홍보 제작 부담과 온라인 진입장벽 완화
- 주민의 동네 가게 발견 및 이용 기회 확대
- 방문 퀘스트를 통한 골목상권 내 소비 순환
- 고령 주민과 이동약자를 포함하는 지역 정보 접근성 향상
- 대학생과 지역 주민이 함께 만드는 지속 가능한 상권 데이터

## 개발 예정 기술

현재 논의된 후보 기술이며, 개발 과정에서 최종 확정할 예정입니다.

- Frontend: React / Next.js 또는 Vue
- Backend: Spring Boot 또는 Node.js / FastAPI
- AI: GPT-4o 또는 Gemini Vision API
- 음성: Google Cloud TTS 또는 네이버 클로바 보이스
- 지도 및 위치: 지도 API, GPS 기반 방문 인증
