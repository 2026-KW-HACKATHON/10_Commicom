# 월계ON-AI

> **[10조 컴미컴]** 사진 한 장으로 시작하는 우리 동네 소상공인 홍보와 골목상권 탐방 서비스

![월계ON-AI 서비스 소개](main.png)

## 프로젝트 소개

월계ON-AI는 서울 노원구 **월계1동**의 소상공인과 주민을 연결하는 지역 상권 활성화 서비스입니다.

사장님은 **사진 몇 장과 한 줄 소개만 입력**하면 AI가 홍보 게시물을 만들어 주고, 게시한 콘텐츠는 **동네 주민의 피드와 지도에 바로 노출**됩니다. 주민은 방문 퀘스트를 통해 실제 골목상권 방문으로 이어집니다.

## 해결하려는 문제

- 소상공인의 디지털 홍보 시간과 역량 부족
- 신메뉴, 할인 등 동네 가게 소식의 전달 부족
- 프랜차이즈와 대형 매장에 집중되는 소비
- 고령 주민과 이동약자가 쓰기 어려운 디지털 서비스

## 핵심 기능

| 기능 | 설명 |
|---|---|
| **AI 홍보물 생성** | 사진과 간단한 소개만으로 홍보 게시물과 숏폼 영상 자동 생성 |
| **동네 피드·지도** | 게시물을 주민 피드와 지도에 바로 노출, 매장 정보와 운영시간 확인 |
| **상권 탐방 퀘스트** | GPS 방문 인증, 스탬프·마일리지 적립, 쿠폰 리워드 |
| **접근성 정보** | 턱 유무, 엘리베이터 등 배리어프리 정보와 큰 글씨 중심 UI |

## 서비스 흐름

```
사장님:      사진·소개 입력   →   AI 게시물 생성   →   검토 후 게시
                                                          ↓
주민:   피드·지도에서 가게 발견 → 퀘스트 참여 → GPS 방문 인증 → 쿠폰 획득
```

## 지역 데이터 기반 문제 정의

| 항목 | 수치 |
|---|---|
| 월계1동 총인구 | 20,133명 |
| 60세 이상 | 6,090명 |
| 20~29세 | 3,654명 |
| 유동인구 최고 시간대 | 17~21시 |
| 매출이 가장 높은 요일 | 토요일 |

20대와 60대 이상이 주요 축인 지역 특성에 맞춰, 학생층의 소비를 골목 안쪽 매장으로 확산하고 고령 주민도 쉽게 이용할 수 있도록 설계했습니다.

## 기술 스택

| 구분 | 기술 |
|---|---|
| Backend | Spring Boot, Swagger |
| Infra | AWS (EC2, S3) |
| AI 영상 생성 | Runway API |
| 영상 편집·타이틀 합성 | FFmpeg |

## 기대 효과

- 소상공인의 홍보 제작 부담과 온라인 진입장벽 완화
- 주민의 동네 가게 발견 및 방문 기회 확대
- 퀘스트를 통한 골목상권 내 소비 순환
- 고령 주민과 이동약자를 포함한 정보 접근성 향상
